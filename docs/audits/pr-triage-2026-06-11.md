| 2 | **CF-unmet wrong ID** | High | `ArrImportService` uses `EntryId == record.MovieId` (lines 356, 392, 406, 436) but queue IDs are Arr API ids (`ArrId`). `SearchExecutor` already uses `ArrId`. |

| 4 | **Config tracker wipe** | Critical (config loss) | `ConfigurationLoader` writes `Trackers = []` for every qBit instance (line 1782). |
| 5 | **Placeholder qBit sections dropped** | High | `orderedQbit` filters `Host == "CHANGE_ME"` (~line 1759). |
| 6 | **Duration save corruption** | High | `durationDisplayToValue` returns suffixed strings (`"5h"`) via `toSuffixed()` (`webui/src/config/durationUtils.ts` ~147). |
| 7 | **HnR bypass in removal loop** | High | `RemoveCompletedTorrentsAsync` calls `ShouldRemoveTorrentAsync` but not `HnrAllowsDeleteAsync` before delete (~690–704). `TorrentProcessor` paths do call `HnrAllowsDeleteAsync`. |
| 8 | **Tagless multi-qBit state bleed** | Medium | `FreeSpaceService` tagless lookups use hash only, not `(Hash, QbitInstance)` (~453–455). |
| 9 | **POST `/api/config` full replace** | High | Host `/api/config` deserializes full JSON vs dotted merge on `/web/config`. |
| 10 | **UrlBase login redirects** | Medium | `LoginPath = "/login"` without UrlBase prefix; SPA path detection incomplete. |

**Not a bug on master:** TokenOnly empty-hash hijack via `IsSetPasswordAllowed` alone — master already requires setup token when unauthenticated. #187/#214 auth hunks for this are largely obsolete; bearer bypass (#171) remains the real auth gap.
